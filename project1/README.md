# Project 1

Basic data exploration and sorting practice.

## Contents
- `sort.ipynb`: Notebook with simple data manipulation / ordering examples.
- `requirements.txt`: Minimal dependencies (`numpy`, `pandas`, `scikit-learn`).

## Setup
From repository root (recommended single shared environment):
```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r project1/requirements.txt
```
(Optional) install Jupyter if not already:
```powershell
pip install jupyter
```

## Run
```powershell
jupyter notebook project1/sort.ipynb
```

## Notes
- Local `venv/` folder (if present) is ignored by Git.
- Prefer using a single root `.venv` instead of multiple nested envs as the repo grows.

See root `README.md` for broader practices and next steps.
